2. What stays on your device2. 기기에만 남는 것

These apps work with technical identifiers by nature — a scan finds IP addresses, an HID remote pairs with a Bluetooth host. Those values are used on the device to make the feature work, are never sent off the device, and are never passed to the advertising SDK: 이 앱들은 성질상 기술적 식별자를 다룹니다 — 스캔은 IP 주소를 찾고, HID 리모컨은 블루투스 host 와 페어링합니다. 이 값들은 기능 동작을 위해 기기 안에서만 쓰이며, 기기 밖으로 나가지 않고 광고 SDK 에도 전달되지 않습니다:

  • Network identifiers found by scanning — IP addresses, hostnames, open ports, device kind 스캔으로 발견한 네트워크 식별자 — IP 주소, hostname, 열린 포트, 장비 종류
  • Bluetooth addresses of hosts you paired with, kept so the app can reconnect. They are deliberately masked in the UI, logs and diagnostic exports. 페어링한 host 의 블루투스 주소 — 재연결을 위해 보관합니다. 화면·로그·진단 export 에는 의도적으로 마스킹해 표시합니다.
  • SSH credentials and TOFU host keys (SSH Scout), held in Android's protected app storage SSH 자격증명과 TOFU 호스트키(SSH Scout) — Android 의 보호된 앱 저장소에 보관
  • Your own settings and preferences 사용자가 지정한 설정값

We do not store device serial numbers or device IDs anywhere. 기기 시리얼 번호나 device ID 는 어디에도 저장하지 않습니다.

Google may process your advertising ID and device information to select and measure ads; that processing is governed by Google's own policies, linked below. 이 앱들은 무료이며 Google AdMob 을 통해 광고를 표시합니다. Google 은 광고 선택·측정을 위해 광고 ID 와 기기 정보를 처리할 수 있으며, 그 처리는 아래 링크의 Google 자체 정책을 따릅니다.

Two rules we hold ourselves to. First, the ad SDK is not initialised until your consent has been resolved through Google's User Messaging Platform — the consent form comes before any ad request. Second, the technical identifiers in section 2 are never handed to the ad SDK; nothing about the network you scanned or the host you paired with reaches an advertiser. 저희가 지키는 두 가지 원칙이 있습니다. 첫째, Google User Messaging Platform 으로 동의가 확인되기 전에는 광고 SDK 를 초기화하지 않습니다 — 동의 창이 어떤 광고 요청보다도 먼저입니다. 둘째, 2절의 기술적 식별자는 광고 SDK 에 전달하지 않습니다. 스캔한 네트워크나 페어링한 host 에 관한 어떤 정보도 광고주에게 가지 않습니다.

You can reopen the privacy options and change or withdraw consent at any time from each app's Settings screen. 각 앱의 설정 화면에서 개인정보 옵션을 언제든 다시 열어 동의를 변경하거나 철회할 수 있습니다.

7. Per-app notes7. 앱별 사항

BT HID Remotecom.droidactor.bthidremote

What you type and where you move the pointer goes over Bluetooth to the host you paired with, and nowhere else. Keystrokes are not logged, stored or transmitted to us — the app keeps only enough state to track which keys are currently held down, in memory. The address of a verified host is stored locally so it can reconnect, masked wherever it is displayed. No location permission is requested. 입력한 키와 포인터 이동은 페어링한 host 로 블루투스를 통해서만 전달되며, 다른 곳으로는 가지 않습니다. 키 입력은 기록·저장되지 않고 저희에게 전송되지도 않습니다 — 앱은 현재 눌려 있는 키를 추적할 만큼의 상태만 메모리에 유지합니다. 검증된 host 의 주소는 재연결을 위해 로컬에만 저장하며, 표시할 때는 마스킹합니다. 위치 권한은 요구하지 않습니다.

PPT Remotecom.droidactor.pptremote

The app sends only five fixed key actions over Bluetooth HID and has no text entry at all. Otherwise it behaves exactly as BT HID Remote above: paired host address stored locally and masked, no location permission, nothing transmitted to us. Ads are shown on the Home, host picker, pairing, settings and about screens only — never on the presenter screen or while connecting, so a running presentation is never interrupted. 블루투스 HID 로 고정된 5개 키 동작만 보내며, 텍스트 입력 기능이 아예 없습니다. 그 외에는 위 BT HID Remote 와 동일합니다 — 페어링 host 주소는 로컬 저장 후 마스킹, 위치 권한 없음, 저희에게 전송되는 것 없음. 광고는 홈·host 선택·페어링·설정·정보 화면에만 표시되며, 발표 화면과 연결 중 화면에는 표시하지 않습니다 — 진행 중인 발표를 방해하지 않기 위해서입니다.

WIFI Scoutcom.droidactor.wifi_scanner

Scanning happens entirely between your phone and the local network it is attached to. Results — IP addresses, hostnames, open ports, device kind — are shown on screen and kept on the device; they are not uploaded anywhere and are not given to the ad SDK. Industrial equipment is treated with extra care: PLC ports are listed as candidates only, and an identity query is a single read-only request sent to one address after you approve that row. The app never writes to such equipment. 스캔은 폰과 접속된 로컬 네트워크 사이에서만 일어납니다. 결과(IP·hostname·열린 포트·장비 종류)는 화면에 표시되고 기기에 남으며, 어디로도 업로드되지 않고 광고 SDK 에도 제공되지 않습니다. 산업용 장비는 더 조심히 다룹니다 — PLC 포트는 후보로만 표시하고, identity 조회는 사용자가 해당 행을 승인한 뒤 한 주소로 보내는 read-only 요청 1회입니다. 이 앱은 그런 장비에 쓰기를 하지 않습니다.

A result row can be handed to SSH Scout by deep link. That link carries the host and port only — never a username or password. 결과 행은 딥링크로 SSH Scout 에 넘길 수 있습니다. 이 링크는 host 와 port 만 싣고, 사용자명·비밀번호는 절대 전달하지 않습니다.

SSH Scoutcom.droidactor.ssh_scout

SSH usernames, passwords, private keys and trust-on-first-use host keys are stored in the app's own protected storage on your device. They are never transmitted to us or to any third party, and are not included in the deep link — the app sandbox means they cannot be read by another app, including WIFI Scout. Terminal sessions connect directly from your phone to the host you specify; no traffic is proxied through us. Session output is not saved off the device. SSH 사용자명·비밀번호·개인키와 TOFU 호스트키는 기기 안 앱 전용 보호 저장소에 보관됩니다. 저희나 제3자에게 전송되지 않으며 딥링크에도 포함되지 않습니다 — 앱 sandbox 가 분리되어 WIFI Scout 을 포함한 다른 앱이 읽을 수 없습니다. 터미널 세션은 폰에서 지정한 host 로 직접 연결되며, 어떤 트래픽도 저희를 경유하지 않습니다. 세션 출력은 기기 밖에 저장되지 않습니다.

YouTube Downloadercom.dualsoft.ytdownloader

The URL you paste is requested directly from your device; we run no download server and never see what you download. Files are written to the location you pick through Android's own file picker, which is why the app asks for no storage permission. A notification shows download progress. No history is sent anywhere — it stays on the device and goes away with the app. 붙여넣은 URL 은 기기에서 직접 요청합니다. 저희는 다운로드 서버를 운영하지 않으며 무엇을 내려받는지 알 수 없습니다. 파일은 Android 파일 선택기로 사용자가 고른 위치에 저장되며, 그래서 앱이 저장소 권한을 요구하지 않습니다. 다운로드 진행 상황은 알림으로 표시됩니다. 기록은 어디로도 전송되지 않고 기기에만 남아 앱과 함께 사라집니다.
