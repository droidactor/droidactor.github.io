Dotori Bluetooth PPT Remote user manual

Pair the phone as a Bluetooth keyboard, test it before the presentation, and control the slideshow with five deliberate actions.

Checked with Android app version 1.0.0 (2) · Updated 14 August 2026

Quick start

  1. Prepare before presenting

    Turn on Bluetooth on the phone and PC. Grant the Bluetooth and notification permissions requested by the app. Open the PC's Bluetooth settings.

  2. Start the connection

    Press Start connection. For a new PC, make the phone discoverable and pair it from the PC. Confirm the request on both devices, then wait for HID registration and the minimum report check to complete.

  3. Open PowerPoint and test

    Bring the PowerPoint window to the foreground. Open the remote, start a test slideshow, and press Next once. Do this before the room fills up so focus or pairing problems are visible early.

  4. Keep the presentation window active

    The remote sends keyboard shortcuts to whichever PC application has focus. Return focus to the slideshow if another window was opened.

The five controls

ControlKey sentPowerPoint result
PreviousPageUpMove to the previous slide
NextPageDownMove to the next slide
From beginningF5, then HomeOpen the slideshow at the first slide
From currentShift+F5Start from the selected slide
EndEscapeLeave the slideshow

The remote is one-way. It can report that a key was sent, but it cannot read the current slide number or confirm that PowerPoint used the key.

Connection and settings

  • Connected PC: shows the current host; use Connect to another PC to change it.
  • Connect to the last PC on startup: attempts one reconnect when Bluetooth is ready and the last PC remains paired.
  • Language: follows the system by default or can be set to English or Korean.
  • Help and app information: lists the exact keys and known limits.

Troubleshooting

SymptomWhat to check
A button does nothingPut the PowerPoint slideshow in the foreground. If the PC was asleep, the first key may only wake it; press the action again.
The wrong app reactsThe wrong PC window has focus. Activate PowerPoint before sending another command.
The phone cannot pairGrant permissions, enable Bluetooth, make the phone discoverable, and close another Dotori HID remote that may own the session.
Start commands differFrom beginning and From current use PowerPoint shortcuts. Another presentation app may use different keys.
The connection ends in the backgroundOpen the app and reconnect. Some phone power-saving policies stop a background Bluetooth session.

Requirements and privacy

  • Android 9.0 or newer on a phone with the Bluetooth HID Device profile
  • A PC that accepts a standard Bluetooth keyboard
  • PowerPoint for the documented start shortcuts

The app sends only the five documented keyboard actions to the paired PC. It cannot read the presentation file, slide content, or current slide. See the full privacy policy.
