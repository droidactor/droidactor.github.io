Dotori SSH Scout

com.droidactor.ssh_scout

SSH 접속·터미널과 TOFU 호스트키 관리에 탐색 기능이 붙어 있습니다. 대부분의 SSH 클라이언트는 주소를 이미 안다고 전제합니다. 이 앱은 네트워크에서 응답하는 host 를 먼저 찾습니다.

출시 준비 중 개인정보

하는 일

host 를 찾고, 접속한다

앱이 열려 있고 Wi-Fi 에 연결되어 있으면, 현재 로컬 IPv4 주소에서 산출한 /24 대역의 host 에 선택한 TCP 포트(기본 22)를 자동으로 시도합니다. 이 자동 탐색이 발견 기능 그 자체입니다.

직접 연결되는 터미널

세션은 폰에서 지정한 host 로 곧장 연결됩니다. 어떤 트래픽도 저희를 경유하지 않습니다 — 경유할 서버 자체가 없기 때문입니다.

TOFU — 처음 본 키를 기억

호스트키는 처음 수락한 시점에 기록되고 이후 접속마다 검사합니다. 키가 바뀌면 조용히 넘어가는 대신 사용자에게 알립니다.

WIFI Scout 에서 넘어오기

Dotori WIFI Scout 의 결과 행이 딥링크로 이 앱을 엽니다. 링크에는 host 와 port 만 실리고 사용자명·비밀번호는 절대 들어가지 않습니다.

자격증명이 있는 곳

SSH 사용자명·비밀번호·개인키와 TOFU 호스트키는 기기 안 앱 전용 보호 저장소에 보관됩니다. 저희나 제3자에게 전송되지 않으며 딥링크에도 포함되지 않습니다. Android 앱 sandbox 때문에 다른 앱은 이를 읽을 수 없습니다 — Dotori WIFI Scout 도 마찬가지이고, 그래서 넘겨받는 것이 주소뿐입니다.

자격증명은 사용자가 저장을 선택하지 않으면 영구 저장하지 않으며, 저장한 것은 저장된 접속 목록에서 대상별로 삭제할 수 있습니다.

본인이 소유하거나 관리 권한을 받은 네트워크에서만 사용하십시오. 접속하는 SSH 서버는 저희가 선택하거나 운영하지 않으므로, 그 서버가 세션을 어떻게 처리하는지는 서버 운영자의 정책이 적용됩니다.

개인정보

세션 출력은 기기 밖에 저장되지 않으며, 접속한 host 에 관한 어떤 정보도 광고 SDK 에 전달되지 않습니다. 계정도, 무언가를 보낼 저희 백엔드도 없습니다.
