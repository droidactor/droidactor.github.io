다시 찾을 장소를 메모와 함께 저장합니다

현재 위치가 측정되면 정확도와 측정 시각을 확인하고 위치를 저장합니다. 메모에는 나중에 알아볼 단서를 적습니다. 예를 들어 공원에서 만난 장소라면 '분수 옆 벤치'처럼 적어 둡니다. 이름만으로 구분하기 어려운 곳도 좌표와 메모를 함께 보면 다시 찾기 쉽습니다.

저장한 지점은 Google 지도·카카오맵·티맵 등 호환 지도 앱으로 엽니다. 다른 사람에게 알려 줄 때는 좌표와 위치 링크를 복사하거나 공유합니다. 메모를 포함할지는 공유할 때 고릅니다. 기록을 검색할 때도 메모와 여정 제목을 이용합니다.

이동하는 동안 여정을 기록합니다

장소 하나를 남기려면 위치 저장을, 이동 경로를 남기려면 여정 기록을 선택합니다. 기록 간격은 시간·이동 거리·두 조건을 모두 만족할 때 중에서 고릅니다. 두 조건을 함께 쓰면 정한 시간이 지나고 정한 거리도 이동해야 다음 지점을 저장합니다. 설정한 주기와 실제 수신 상태에 따라 기록되는 지점 수는 달라집니다.

  1. 출발할 때 앱에서 기록을 시작합니다.
  2. 남겨 두고 싶은 곳에서는 위치를 저장해 여정의 중요 지점으로 묶습니다.
  3. 쉬는 동안에는 일시정지하고, 다시 이동할 때 재개합니다.
  4. 도착하면 기록을 종료하고 여정 요약을 확인합니다.

사용자가 시작한 여정은 화면이 꺼진 동안에도 기록을 이어갑니다. 알림을 허용한 환경에서는 기록 알림으로 일시정지·재개·종료를 조작합니다. 재부팅이나 앱 강제 종료 뒤에는 자동으로 새 기록을 시작하지 않습니다. 기록을 마쳤다면 종료 상태를 확인해 두는 편이 좋습니다.

지도와 경로 그림에서 기록을 확인합니다

첫 화면 지도에서는 저장한 장소와 이동 경로를 확인합니다. 여정 요약에는 거리·경과 시간·이동 시간·평균 및 최고 속도·고도 상승·지점 수가 표시됩니다. 경과 시간과 이동 시간이 따로 있어 쉬어 간 시간과 움직인 시간을 구분해 봅니다. 값은 기기가 받은 위치를 바탕으로 계산합니다.

여정의 경로 미리보기는 지도 배경 없이 선과 지점으로 경로를 보여 줍니다. 첫 화면 지도와는 별개의 화면입니다. 이 글의 화면은 공공장소 좌표로 만든 시연용 기록이며 개인의 이동 이력이 아닙니다. 같은 길을 걸어도 기기와 수신 환경에 따라 결과가 달라집니다.

GPX로 꺼내고 JSON으로 백업합니다

여정과 중요 지점은 GPX로 내보내 호환 앱이나 도구에서 확인합니다. 전체 기록을 다른 기기로 옮길 때는 JSON 백업을 이용합니다. JSON 복원은 확인 후 기존 기록 전체를 바꾸므로, 남길 기록이 있다면 먼저 백업합니다. GPX 내보내기와 전체 기록 백업은 용도가 다릅니다.

좌표·경로·메모는 앱의 기기 저장소에 보관합니다. 지도 표시와 외부 지도 열기, 사용자가 선택한 공유·내보내기에는 각 서비스의 데이터 처리가 따릅니다. 배너 광고가 표시될 수 있으며 광고 데이터는 별도로 처리합니다. GPS 좌표·이동 이력·메모를 광고 요청에 넣지는 않습니다.

Android 8.0 이상과 위치 권한이 필요합니다. 지도 표시에는 네트워크가 필요할 수 있고, 위치 정확도는 기기·주변 환경·권한 설정에 따라 달라집니다. 수신이 끊기면 경로에 공백이 생길 수 있습니다. 긴급 구조나 전문 측량을 보장하는 앱은 아닙니다.
