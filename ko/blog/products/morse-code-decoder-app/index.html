모스부호 번역기, 소리와 두드리기도 읽기

2026년 10월 30일

요약. 점 세 개, 선 세 개, 다시 점 세 개를 적어 봅니다. 익숙한 SOS도 직접 소리를 듣거나 손으로 누르면 점과 선을 구분하는 일이 달라집니다.

도토리 모스소리·두드리기·텍스트에서 모스 부호를 읽으세요.

도토리 모스는 안드로이드에서 모스 부호를 읽는 앱입니다. 점·선 텍스트뿐 아니라 화면을 누르는 길이와 일정한 높이의 소리도 입력으로 받습니다. 국제 모스, 한글 모스, 일본어 와문 중 읽을 부호표를 고르고 원래 부호와 해독 문장을 함께 확인합니다.

점과 선을 붙여 넣고 문자로 바꿉니다

문제로 받은 부호나 메모에 적어 둔 점·선은 텍스트 화면에 넣습니다. 글자 사이는 공백으로, 단어 사이는 /로 나눕니다. ... --- ...처럼 입력하면 글자별로 구분된 부호를 읽습니다.

반대로 지원하는 문자를 넣어 모스 부호로 바꾸는 기능도 있습니다. 먼저 짧은 단어를 변환해 보고, 같은 부호를 다시 해독하며 글자와 부호를 익히는 식입니다. 부호표를 일일이 오가며 옮겨 적는 수고를 줄입니다.

화면을 짧게 누르거나 길게 눌러 입력합니다

화면 두드리기는 휴대전화의 입력 키를 직접 누르는 방식입니다. 짧은 누름과 긴 누름을 점과 선으로 읽습니다. 문자 종료와 단어 띄우기 버튼으로 구분하고, 잘못 누른 마지막 점·선은 취소합니다.

입력 중인 글자는 결과 끝에 부호로 보입니다. 무엇을 누르고 있는지 살펴보면서 입력을 이어 갑니다. 손가락의 누름 속도에 맞춰 설정에서 점 길이를 바꾸는 것도 가능합니다.

세 가지 입력은 아래처럼 나눠 쓰면 됩니다.

  1. 이미 적힌 점·선이 있으면 텍스트 화면에 붙여 넣습니다.
  2. 직접 부호를 보내는 느낌을 익히려면 화면 키를 누릅니다.
  3. 일정한 높이의 모스 소리가 있으면 마이크나 WAV 파일로 읽습니다.

책상을 두드리는 충격음은 화면 두드리기와 다릅니다. 손으로 화면을 누르는 입력과 마이크가 듣는 소리를 구분해 사용합니다.

소리 입력은 일정한 높이의 모스 톤을 읽습니다

소리 화면에서는 마이크로 모스 톤을 듣거나 지원하는 PCM WAV 파일을 엽니다. 자동 주파수 탐색과 수동 조정을 제공하므로 소리의 높이와 속도에 맞춰 설정을 확인합니다. 주변 잡음이나 입력 상태에 따라 해독 결과는 달라집니다.

음성이나 임의의 충격음을 문자로 바꾸는 앱은 아닙니다. MP3와 동영상, 압축 WAV는 지원하지 않습니다. 마이크는 앱이 화면에 보이는 동안에만 사용하며 원시 마이크 소리를 녹음 파일로 저장하거나 업로드하지 않습니다.

한글과 와문은 설정에서 부호표를 고릅니다

국제 모스와 한글 모스, 일본어 와문은 설정에서 선택합니다. 휴대전화 메뉴가 한국어여도 국제 모스로 읽을 수 있고, 영어 메뉴에서도 한글 부호표를 고릅니다. 앱의 표시 언어와 해독할 부호 체계는 따로 정합니다.

한글은 음절 경계가 모호할 수 있어 원래 부호와 받은 자모, 해석 후보를 함께 살펴보는 편이 좋습니다. 일본어 작은 가나는 큰 가나로 바뀌어 원래 크기를 복원하지 못합니다. 결과 문장을 손으로 고쳐도 원문 부호와는 별도로 보관하므로 나중에 다시 비교합니다.

복사와 모스 소리 재생을 지원하고, 사용자가 저장한 최근 기록은 최대 30개까지 기기에 남습니다. 해독에는 계정이 필요하지 않습니다. 광고가 표시될 수 있으며 광고 SDK가 처리하는 데이터는 입력 내용이나 해독 문장과 구분됩니다.
