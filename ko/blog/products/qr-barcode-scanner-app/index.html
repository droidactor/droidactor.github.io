QR 코드 인식 앱으로 전면 광고 없이 링크 주소를 먼저 확인하는 법

2026년 11월 14일 · 수정 2026년 11월 20일

https://play.google.com/store/apps/details?id=com.droidactor.qr

요약. 식당 테이블에서 메뉴판 QR을 찍었는데 메뉴 대신 전면 광고가 화면을 덮고, 닫기 버튼을 누르려다 유료 부가서비스 가입 창으로 넘어가는 일이 자주 벌어집니다. 도토리 QR·바코드 스캐너는 카메라·사진·공유 이미지에서 QR 코드와 바코드를 읽고, 결과 화면에서 원하는 동작을 직접 고르는 안드로이드 앱입니다. 스캔 직후 화면을 가리는 전면 광고나 유료 구독 유도 화면이 없으며, 웹 링크를 열기 전에 실제 이동할 도메인과 주소 모양을 먼저 보여 줍니다.

도토리 QR·바코드 스캐너찍으면 바로 결과, 링크는 열기 전에 확인

이 앱은 다섯 가지 핵심 기능을 중심으로 동작합니다. 카메라와 갤러리 사진, 다른 앱에서 공유한 이미지 속 QR 코드 및 1차원·2차원 바코드를 휴대폰 안에서 바로 판독합니다. 웹 링크는 자동으로 열지 않고 이동할 도메인과 전체 주소, 단축 URL이나 앱 설치 파일 여부 같은 주소 특징을 먼저 안내합니다. 화면 가운데 가이드 상자 안에 들어온 코드만 읽어 주변의 다른 코드가 먼저 찍히는 불편을 막습니다. Wi-Fi 추가, 연락처·일정 등록, 상품 바코드 웹 검색 등 코드 종류에 맞는 동작을 결과 화면에서 직접 실행합니다. 읽은 코드는 기기 안에 최대 500개까지 남기며 검색과 개별·전체 삭제를 지원합니다.

스캔할 때마다 뜨는 전면 광고와 자동 실행을 없앴습니다

QR 코드를 찍는 순간 화면 전체를 덮는 광고가 뜨면 결과를 확인하기 전에 닫기 버튼부터 찾아야 합니다. 닫기 표시가 작거나 위치가 매번 바뀌면 원하지 않는 광고 페이지나 통신사 유료 부가서비스 안내 화면을 누르기 쉽습니다.

도토리 QR·바코드 스캐너에는 스캔 전후로 끼어드는 전면 광고나 유료 업그레이드 유도 창이 없습니다. 모든 기능은 무료이며 구독이나 인앱 결제를 요구하지 않습니다. 광고는 화면 위쪽의 배너 하나뿐이고, 아래쪽 조작 버튼과 간격을 띄워 두어 스캔하거나 결과를 누르는 중에 잘못 건드리기 어렵습니다.

코드를 읽자마자 브라우저가 저절로 열리거나 Wi-Fi·연락처가 자동으로 저장되지도 않습니다. 어떤 형식의 코드든 먼저 스캔 결과 화면을 열고, 사용자가 내용을 눈으로 확인한 뒤 버튼을 눌렀을 때만 다음 동작을 실행합니다.

링크를 열기 전에 이동할 도메인과 주소 안내를 먼저 봅니다

종이 전단이나 현장 안내판, 주차 정산기에 붙은 QR 코드는 눈으로 글자를 읽을 수 없어 어느 사이트로 연결되는지 미리 알기 어렵습니다. 이 앱으로 웹 링크 QR을 읽으면 이동할 곳 아래에 도메인 이름을 큰 글씨로 먼저 보여 주고, 바로 아래 줄에 전체 주소를 빠짐없이 표시합니다.

주소의 생김새에 한 번 더 살펴볼 특징이 있으면 주소 안내 상자에 해당 항목을 함께 띄웁니다.

  1. 실제 도착 주소가 가려져 열어야 보이는 단축 URL 서비스 주소
  2. 암호화하지 않는 일반 연결(http) 주소
  3. 도메인 이름 대신 숫자로만 적힌 IP 숫자 주소
  4. 로마자 이외의 글자나 xn-- 표기(국제화 문자)가 들어간 주소
  5. 주소 중간의 @ 기호 앞에 사용자 정보가 들어간 형태
  6. 누르면 안드로이드 앱 설치 파일을 내려받는 .apk 링크

예를 들어 http://bit.ly/... 형태의 코드를 읽으면 화면에 bit.ly 도메인과 전체 주소를 먼저 띄웁니다. 그 아래에는 암호화하지 않는 주소라는 점과 단축 URL 서비스라는 점을 나란히 알려 줍니다. 이 안내는 주소의 모양만 알려 주며 사이트가 안전한지 대신 판정하지는 않습니다. 사용자는 표시된 도메인과 안내를 확인한 뒤 브라우저로 열기, 복사, 공유, 원문 보기 중에서 필요한 동작을 직접 고르면 됩니다.

카카오톡과 스크린샷 속 QR도 공유 메뉴로 바로 읽습니다

모바일 초대장, 행사 입장권, 할인 쿠폰처럼 내 휴대폰 화면에 떠 있는 QR 코드를 읽어야 할 때도 많습니다. 다른 사람의 휴대폰이나 PC 모니터에 띄워 다시 찍을 필요 없이, 휴대폰 안에 있는 이미지를 두 가지 경로로 바로 판독합니다.

첫째는 앱 첫 화면 아래의 사진 버튼을 눌러 갤러리에 저장된 사진이나 스크린샷을 고르는 방법입니다. 둘째는 카카오톡·갤러리·브라우저 등 다른 앱에서 이미지를 보다가 공유 메뉴를 열고 도토리 QR·바코드 스캐너로 바로 보내는 방법입니다.

공유 메뉴를 쓰면 대화방에 올라온 QR 이미지를 기기 앨범에 따로 저장했다가 다시 지우는 과정을 거치지 않아도 됩니다. 이미지 안의 코드는 전체 영역에서 찾으며, 사진이 회전되어 있어도 방향을 맞춰 읽어 냅니다. 판독에 사용한 이미지는 코드를 읽는 데만 쓰고 앱 안에 따로 저장하지 않습니다.

가이드 상자 안의 코드만 골라 읽고 어두운 곳에서도 조절합니다

식당 테이블 스티커나 행사장 포스터에는 메뉴 주문용 QR, 영수증 리뷰 이벤트 QR, 소셜 미디어 홍보 QR이 좁은 간격으로 나란히 인쇄되어 있는 경우가 흔합니다. 카메라 화면 전체에서 아무 코드나 먼저 잡으면 내가 겨누지 않은 옆 코드가 반복해서 찍힙니다.

도토리 QR·바코드 스캐너는 카메라 화면 가운데에 표시된 가이드 상자 안에 들어온 코드만 읽습니다. 상자 바깥에 있는 코드는 무시하므로 원하는 코드 하나만 상자 안에 맞추면 됩니다. 만약 좁은 면적에 작은 코드 여러 개가 붙어 있어 가이드 상자 안에 두 개 이상이 동시에 들어오면, 그중 어느 코드를 열지 화면에서 직접 하나를 고를 수 있습니다.

어두운 실내나 야간 주차장에서는 화면 아래의 손전등 버튼을 눌러 조명을 켭니다. 멀리 붙어 있거나 인쇄 크기가 작은 코드는 미리보기 화면을 두 손가락으로 펼쳐 확대하고, 초점이 흐릴 때는 화면에서 코드 위치를 가볍게 눌러 초점을 맞춥니다.

Wi-Fi 추가부터 연락처·상품 바코드 검색까지 코드 종류에 맞게 실행합니다

읽어 들인 코드의 내용에 따라 결과 화면의 항목 구성과 실행 버튼이 달라집니다. 2차원 코드는 QR 코드, Aztec, Data Matrix, PDF417을 읽습니다. 1차원 바코드는 EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, Codabar, ITF를 지원합니다.

카페나 사무실의 Wi-Fi QR을 읽으면 네트워크 이름과 보안 방식, 비밀번호를 화면에 한눈에 보여 줍니다. Android 11 이상 기기에서는 이 Wi-Fi 추가를 눌러 시스템 Wi-Fi 등록 확인 창을 바로 엽니다. 이전 버전이나 수동 입력이 필요한 환경에서는 비밀번호 복사와 Wi-Fi 설정 열기 버튼을 이어서 쓰면 됩니다.

명함이나 행사 부스의 연락처 QR을 읽으면 이름, 회사·기관, 직함, 전화번호, 이메일, 웹사이트를 항목별로 정리해 보여 줍니다. 연락처에 추가나 일정 QR의 달력 추가를 누르면 앱이 주소록·캘린더 권한을 직접 요구하지 않고 안드로이드 기본 앱의 작성·확인 화면으로 값을 넘겨 줍니다. 최종 저장 전에 내용을 눈으로 한 번 더 확인하고 고칠 수 있습니다.

과자, 음료, 생활용품 겉면의 EAN-13이나 UPC 상품 바코드를 비추면 바코드 형식과 숫자를 읽고 웹에서 검색 버튼으로 브라우저 검색 결과를 바로 열 수 있습니다. 일련번호만 따로 필요할 때는 복사를 눌러 클립보드에 담으면 됩니다.

카메라 권한만 요청하고 스캔 기록은 휴대폰 안에서만 관리합니다

앱이 요청하는 기기 권한은 카메라 하나뿐입니다. 위치, 주소록, 달력, 저장소 전체 읽기, 마이크 권한은 요청하지 않습니다. 카메라 권한을 허용하지 않더라도 갤러리에서 사진을 고르거나 다른 앱의 공유 메뉴로 이미지를 보내 QR·바코드를 읽는 기능은 그대로 작동합니다. 코드 판독은 인터넷 연결 없이 휴대폰 안에서 이루어지며 카메라 화면이나 사진 파일을 외부 서버로 보내지 않습니다.

읽은 코드는 최신순으로 최대 500개까지 이 휴대폰의 앱 전용 저장소에 남습니다. 스캔 기록 화면 위쪽 검색창에 도메인이나 이름, 바코드 숫자를 입력하면 이전에 읽었던 기록을 다시 찾습니다. 필요 없는 항목은 줄마다 있는 휴지통 아이콘이나 모두 삭제로 정리합니다. 기록을 남기고 싶지 않다면 설정에서 기록 저장을 끄면 되며, 저장된 기록은 안드로이드 자동 백업이나 기기 간 이전 대상에서 제외됩니다.
