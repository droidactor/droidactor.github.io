도토리 파일 금고어떤 파일이든 암호화해 나만 봅니다

앱을 삭제하면 금고 안에 보관된 파일도 모두 삭제됩니다. 삭제 전에는 반드시 필요한 파일을 ‘꺼내기’로 내보내고, 저장한 파일이 열리는지 확인하세요. 앱을 다시 설치하거나 같은 비밀번호를 입력해도 지워진 금고가 돌아오지는 않습니다.

사진과 문서를 함께 넣고 폴더로 정리하며, 사진·동영상·PDF·텍스트는 앱 안에서 봅니다. 파일을 넣은 뒤에는 암호화본이 원본과 일치하는지 확인하고 원본 삭제를 안내합니다. 잠금 해제에는 비밀번호나 지원 기기의 지문을 쓰고, 폰을 바꿀 때를 위한 암호화 백업도 만듭니다. 보관부터 열람·원본 정리·내보내기까지 한 앱에서 처리하는 구성입니다.

사진뿐 아니라 PDF와 문서도 함께 보관합니다

사진 숨기기가 필요할 때 갤러리의 사진만 따로 옮기면, 다운로드 폴더에 있는 계약서나 신분증 PDF는 그대로 남습니다. 도토리 파일 금고에는 사진·동영상 외에도 문서와 ZIP 같은 여러 형식의 파일을 넣습니다. 파일 형식에 따라 서로 다른 보관 앱을 찾을 필요가 줄어듭니다.

금고 안에는 비밀 폴더처럼 쓸 폴더를 만들어 파일을 나눠 둡니다. 신분증 사본과 계약서를 문서 폴더에 모으고, 개인 사진은 다른 폴더에 두는 식입니다. 갤러리에서 찾는 사진과 파일 앱에서 찾는 문서를 같은 목록에서 관리합니다.

파일을 가져올 때는 앱의 사진·동영상 또는 파일 버튼으로 원하는 항목을 고릅니다. 다른 앱에서 파일을 선택한 뒤 공유 메뉴로 금고에 보내는 방법도 있습니다. 모든 파일을 앱이 알아서 가져오는 방식이 아니라, 보관할 것을 직접 고르는 방식입니다.

원본은 금고에 들어갔는지 확인한 뒤 지웁니다

파일 암호화가 끝났다고 곧바로 원본을 지우지는 않습니다. 앱은 가져온 암호화본을 다시 풀어 원본과 크기가 같은지, 파일 내용을 대조하는 SHA-256 값이 같은지 확인합니다. 이 검증이 끝난 파일에 대해 원본 삭제를 안내합니다.

동영상 숨기기도 금고에 넣는 것과 원본을 지우는 것을 나눠 생각해야 합니다. 금고 안에 사본이 생겨도 원본이 갤러리에 남아 있으면 다른 사람이 그 원본을 볼 수 있습니다. 기본 설정에서는 원본 자동 삭제가 꺼져 있으므로, 넣은 뒤의 안내를 읽고 삭제 여부를 고르세요.

처리 순서는 다음과 같습니다.

  1. 보관할 파일을 선택해 금고에 넣습니다.
  2. 앱이 암호화본을 검증하고 처리 결과를 보여 주는지 확인합니다.
  3. 가져오기 결과 안내에서 ‘원본 삭제’를 선택하고, Android의 확인 화면이 나오면 승인합니다.
  4. 삭제 결과를 확인한 뒤 금고 안에서 파일을 열어 봅니다.

원본을 지우기 전에 내용을 직접 보고 싶다면 안내에서 ‘남겨 두기’를 고르세요. 금고 안에서 파일을 열어 확인한 다음, 갤러리나 파일 앱에서 원본을 직접 지웁니다. 금고 목록의 ‘삭제’는 금고에 보관한 파일을 지우는 기능이므로 구별해야 합니다.

원본을 제공한 앱의 권한에 따라 삭제하지 못하는 파일도 있습니다. 특히 공유 메뉴로 받은 파일은 보낸 앱에 원본이 남습니다. 앱이 보여 주는 삭제 결과를 읽고, 남은 원본은 해당 갤러리나 파일 앱에서 확인해야 합니다.

Google 포토 같은 클라우드 백업과 갤러리 휴지통에 남은 사본도 별개입니다. 금고에서 원본을 삭제해도 그곳의 사본까지 함께 지워지지는 않습니다. 원본 삭제는 일반적인 파일 삭제이며, 복구가 불가능하도록 지우는 완전 삭제 기능은 아닙니다.

사진·동영상·PDF·텍스트는 금고 안에서 봅니다

계약서 내용을 잠깐 확인하려고 문서를 꺼냈다가 다시 넣는 일은 번거롭습니다. 도토리 파일 금고는 문서 암호화가 필요한 PDF를 보관하고 앱 안에서 읽도록 지원합니다. 지원하는 사진·동영상·텍스트도 암호화되지 않은 일반 파일 사본을 따로 저장하지 않고 봅니다.

보관 가능한 형식과 앱 안에서 바로 보는 형식은 다릅니다. 사진·동영상·PDF·텍스트 외의 문서나 ZIP 등은 필요할 때 다른 앱으로 엽니다. 이때 상대 앱은 풀린 파일을 받으므로 사본을 남길 수 있다는 점을 알아 두세요.

비밀번호와 지문으로 열고 화면을 끄면 잠깁니다

금고를 만들 때 비밀번호를 정하고 복구 키를 따로 보관합니다. 지문을 지원하는 기기에서는 지문 잠금 해제도 사용합니다. 설정에서 비밀번호, 지문 또는 둘 다를 사용하는 방법을 고릅니다.

화면을 끄면 금고가 잠기며, 앱을 벗어날 때도 잠깁니다. 다만 앱에서 띄운 파일 선택·삭제 확인 화면이나 다른 앱으로 열기 중에는 최대 5분 동안 잠금을 유예합니다. 파일을 고르거나 삭제를 승인하는 도중에 금고가 바로 닫히지 않도록 둔 예외입니다.

일반적인 사용 환경에서는 화면 캡처와 최근 앱 목록의 미리보기도 차단합니다. 루팅했거나 이미 침해된 기기까지 완벽하게 보호한다고 보장하지는 않습니다. 금고 밖으로 꺼낸 파일과 다른 앱이 만든 사본은 각 보관 위치에서 따로 관리해야 합니다.

꺼내기와 암호화 백업에 별도 요금이 없습니다

파일을 보관할 때만큼 다시 꺼낼 때도 비용을 확인하게 됩니다. 도토리 파일 금고는 꺼내기와 백업을 포함한 모든 기능이 무료이며 구독이나 꺼내기 요금이 없습니다. 화면 위쪽에는 배너 광고가 있습니다.

파일을 일반 파일로 되돌리는 꺼내기와 금고를 통째로 옮기기 위한 백업은 용도가 다릅니다.

꺼내기는 고른 저장 위치에 일반 파일을 만듭니다. 저장한 파일은 다른 앱에서도 보이므로 보관 위치를 직접 고르세요. 파일을 내보낸 뒤에는 저장 위치에서 직접 열어 보고 내용이 맞는지 확인하는 것이 좋습니다.

백업은 설정의 ‘백업 파일 만들기’에서 생성합니다. 새 폰으로 옮길 목적이라면 PC나 직접 선택한 클라우드 저장소처럼 지금 폰 밖에 보관해야 합니다. 복원할 때는 백업을 만들 당시의 비밀번호나 복구 키가 필요합니다.

개발자 계정이나 클라우드 자동 동기화는 없습니다. 금고의 파일 내용과 이름을 개발자나 광고 SDK에 보내지 않습니다. 다만 사용자가 클라우드 저장 위치를 골라 꺼내기나 백업을 하면 그 서비스에 저장되며, 광고에는 네트워크와 광고 SDK가 사용됩니다.

앱을 삭제하기 전에는 반드시 파일을 내보내세요

앱 삭제 전 파일 내보내기는 반드시 해야 합니다. 앱을 삭제하거나 앱 데이터를 지우면 이 폰의 금고와 그 안의 파일이 모두 사라집니다.

금고에 넣으면서 원본까지 삭제했다면, 밖에 보관해 둔 사본이나 백업 없이는 파일을 되찾지 못합니다.

삭제 전에는 다음 순서로 확인하세요.

  1. 금고에 있는 필요한 파일을 ‘꺼내기’로 앱 밖의 저장 위치에 내보냅니다.
  2. 저장한 위치에서 파일들을 직접 열어, 필요한 파일이 빠지지 않았는지 확인합니다.
  3. 금고 상태로도 보관하려면 암호화 백업을 만들어 폰 밖에 별도로 저장합니다.
  4. 내보낸 파일과 저장 위치를 확인한 다음 앱을 삭제합니다.

Android 자동 백업이나 새 폰으로 기기를 이전하는 기능에는 금고가 포함되지 않습니다. 앱을 다시 설치해 같은 비밀번호·지문·복구 키를 사용해도 삭제된 파일이 저절로 돌아오지는 않습니다. 비밀번호와 복구 키는 남아 있는 금고나 백업을 여는 수단이며, 파일 자체를 대신하지 못하기 때문입니다.

미리 만든 백업이 있다면 앱의 처음 화면에서 ‘백업에서 복원’을 선택합니다. 복원되는 내용은 그 백업을 만들 때까지의 파일입니다. 백업 이후에 추가한 파일도 보관하려면 삭제 전에 최신 백업을 다시 만들어야 합니다.

사진과 문서를 한곳에 보관하고, 꺼내기와 백업까지 무료로 쓰려면 도토리 파일 금고를 살펴보세요. 처음에는 중요하지 않은 파일 하나로 넣기·열람·꺼내기를 해 보시기 바랍니다. 앱을 지우기 전에는 반드시 파일을 내보내고, 밖에 저장한 파일이 열리는지 확인하세요.
