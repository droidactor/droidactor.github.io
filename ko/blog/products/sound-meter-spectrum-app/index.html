요약. 밤늦게 천장에서 울리는 쿵쿵거림이나 냉장고·에어컨의 높은 작동음이 어느 정도인지 확인하려다, 화면을 덮는 전면 광고나 유료 결제 창 앞에서 측정을 멈추는 일이 잦습니다. 도토리 소음 측정기는 계정과 구독, 전면 광고 없이 열자마자 실시간 데시벨 측정과 주파수 분포 확인, 구간 기록까지 무료로 쓰는 소음 측정기 어플입니다. 제가 만든 무료 소음 측정기이며, 소리는 폰 안에서만 분석하고 원음 파일은 저장하지 않습니다.

도토리 소음 측정기실시간 dB·주파수 스펙트럼 측정과 무료 CSV·이미지 기록

앱은 측정과 기록 두 탭으로 나뉩니다. 측정 탭에서는 실시간 데시벨과 최소·평균(Leq)·최대 수치, 최근 60초 시간 추이 그래프, 저·중·고 3대역과 28대역 주파수 스펙트럼을 한 화면에서 봅니다. 상단 칩을 눌러 dBA·dBC·dBZ 가중치, 빠름·느림 응답 속도, 0.1 dB 단위의 기기 보정을 바로 바꿉니다. 기록 탭에서는 직접 시작한 구간 기록을 다시 열어 시간대별 수치를 훑어보고, 메모를 적거나 세션 전체를 CSV와 요약 이미지(PNG)로 저장·공유합니다.

열자마자 실시간 데시벨과 60초 추이를 확인합니다

측정 탭에서 마이크 권한을 허용하면 곧바로 데시벨 측정기 화면이 움직입니다. 가운데 큰 숫자가 현재 데시벨이고, 바로 아래에 최소·평균(Leq)·최대 값이 함께 표시됩니다. 여기서 평균(Leq)은 숫자만 단순 평균한 값이 아니라 소리의 에너지를 기준으로 계산한 등가 소음도입니다. 잠깐 크게 울린 순간이 전체 체감에 주는 영향을 반영해 줍니다.

숫자 아래 그래프는 최근 60초 동안의 변화를 0~130 dB 범위로 보여 줍니다. 측정하는 동안 주변 소리가 폰 마이크의 허용 범위를 넘으면 화면에 '입력 포화(신뢰 불가)' 경고가 뜨고 그래프에 빨간 점으로 남습니다. 반대로 다른 앱이나 통화 때문에 마이크 입력이 끊긴 구간은 0 dB로 메우지 않고 빈 구간으로 비워 두며 평균(Leq) 계산에서도 제외합니다.

실시간 확인은 아래 순서로 진행합니다.

  1. 측정 탭을 열고 마이크 권한을 허용합니다.
  2. 현재 수치와 일상 비유 문구, 최근 60초 그래프에서 소리의 높낮이 변화를 확인합니다.
  3. 특정 시간대의 변화를 남겨 두려면 아래쪽 구간 기록 버튼을 누릅니다.
  4. 새 측정을 시작하기 전에 수치를 비우고 싶으면 초기화 버튼을 누릅니다.

참고용 층간소음 측정기로 집안 소리를 살펴볼 때도 같은 흐름입니다. 측정이 끝나기 전에 화면을 끄거나 다른 앱으로 옮기면 마이크를 바로 닫아 불필요한 입력을 막습니다.

저·중·고 3대역과 28대역 주파수 스펙트럼으로 소리의 성격을 비교합니다

전체 데시벨 숫자 하나만 보면 낮은 울림과 날카로운 기계음이 같은 크기로 보일 때가 많습니다. 도토리 소음 측정기는 주파수 분석기 역할을 함께 갖췄습니다. 측정 화면 아래쪽에 저주파(20~250 Hz)·중주파(250 Hz~2 kHz)·고주파(2~16 kHz) 3대역 막대를 상시 표시합니다. 발걸음이나 둔탁한 울림처럼 낮은 대역이 큰 소리와, 가전제품 팬이나 고주파 마찰음처럼 높은 대역이 큰 소리를 상대적으로 비교해 봅니다.

3대역 카드 아래의 '상세 스펙트럼 보기'를 누르면 40 Hz부터 16 kHz까지 나눈 28대역 로그 주파수 스펙트럼이 펼쳐집니다. 오른쪽 위에 가장 에너지가 큰 피크 주파수(Hz)도 함께 나옵니다. 큰 데시벨 숫자를 dBA나 dBC로 두고 보더라도 3대역과 28대역 막대는 항상 비가중(Z) 상대 비교로 그려지므로, 어떤 대역의 비중이 커졌는지 비교하기 편합니다.

대역 구분주파수 범위활용 예시
저주파20~250 Hz둔탁한 울림, 대형 팬·배관 저음 비교
중주파250 Hz~2 kHz사람 말소리, TV·생활 배경음 비교
고주파2~16 kHz가전제품 작동음, 날카로운 마찰음 비교

스마트폰 마이크는 기종마다 주파수별 감도 특성이 다르고, 특히 저주파 대역은 하드웨어에서 작게 잡히는 경우가 많습니다. 대역 막대와 스펙트럼은 절대 크기를 재는 용도보다, 같은 폰에서 평소와 소리가 날 때의 차이를 비교하는 참고 자료로 쓰는 편이 맞습니다.

dBA·dBC·dBZ 가중치와 0.1 dB 단위 기기 보정을 지원합니다

측정 화면 위쪽의 가중치·응답·보정 상태 칩을 누르면 설정 시트가 바로 열립니다. 주파수 가중치는 IEC 61672-1 기준의 A·C·Z 세 가지 중 고릅니다. 일상 소음 비교에는 저주파 비중을 줄인 dBA를 기본으로 쓰고, 저주파 에너지를 더 살려 보고 싶으면 dBC, 가중치를 적용하지 않은 원시 분포를 볼 때는 dBZ를 선택합니다. 응답 속도는 순간 변화에 민감한 빠름(125 ms)과 흔들림을 완만하게 보는 느림(1초) 두 가지입니다.

같은 소리를 재도 스마트폰 모델마다 표시 숫자가 몇 dB씩 다릅니다. 앱은 현재 보정 상태를 '기기 감도값 사용', '기본값 · 미보정', '사용자 보정' 세 가지 칩으로 분명하게 구분합니다. 실제 내장 마이크와 원시 입력 경로의 감도값이 확인될 때만 제조사 감도값을 쓰고, 그 밖의 기기는 미보정 기본값임을 숨기지 않고 보여 줍니다.

별도의 기준 소음계가 있다면 같은 안정된 소리 앞에서 두 수치를 비교한 뒤 기기 보정 오프셋을 조절합니다. −30.0 dB부터 +30.0 dB까지 ±0.1 dB 또는 ±1.0 dB 단위로 맞추고, 변경한 날짜가 함께 기록됩니다. 다만 단일 숫자 오프셋은 전체 수치를 평행 이동할 뿐이므로 마이크의 주파수 응답 곡선까지 고치지는 못합니다. 입력 장치가 바뀌거나 OS가 업데이트되면 오프셋을 다시 확인하는 편이 안전합니다.

구간 기록을 저장하고 CSV와 요약 이미지로 무료 내보냅니다

실시간 화면을 지켜보기만 하면 몇 분 전 수치가 금세 지나갑니다. 측정 탭에서 구간 기록을 누르면 1초마다 최소·평균(Leq)·최대 데시벨과 3대역 수치, 피크 주파수, 입력 포화 여부를 기기 내부에 기록합니다. 한 세션은 유효 측정 기준 최대 4시간까지 저장합니다. 기록하는 동안 측정 기준이 섞이지 않도록 가중치·응답·보정값은 고정되며, 설정을 바꾸려면 현재 구간을 끝내고 새 구간으로 시작하게 안내합니다.

기록 탭에서 저장된 항목을 열면 전체 시간 추이 그래프가 나타납니다. 그래프 위를 손가락으로 누르거나 좌우로 끌면 해당 초의 데시벨과 저·중·고 대역 수치, 피크 주파수가 아래에 표시됩니다. 필요한 메모를 적어 저장한 뒤, 세션 전체를 UTF-8 CSV 파일이나 1080×1440 요약 이미지(PNG)로 저장하거나 다른 앱으로 바로 공유합니다. CSV에는 보정 상태와 가중치, 누락 구간 정보, 1초 단위 행이 모두 담깁니다. 이 모든 저장과 내보내기에는 유료 잠금이 없습니다.

집에서 참고용 층간소음 측정 기록을 정리하거나 가전제품 수리 전후 소리를 비교할 때 쓰기 좋습니다. 요약 이미지 한 장으로 평균·최대·추이 그래프를 한눈에 남기거나, CSV를 표 계산 프로그램에서 열어 시간대별 변화를 살펴봅니다.
