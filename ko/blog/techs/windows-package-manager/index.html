윈도우 프로그램 설치를 명령 한 줄로 끝내는 세 가지 도구

2026년 9월 2일

요약. 이 컴퓨터에서 winget upgrade 를 한 번 쳐 봤습니다. 업데이트가 밀린 프로그램이 42개 나왔습니다. 와이어샤크, yt-dlp, 이름조차 잊고 있던 도구들이 줄줄이 올라왔습니다. 홈페이지를 하나씩 찾아 설치 파일을 내려받았다면 반나절 걸리는 일입니다.

제가 만든 무료 앱입니다. 많이 써 주세요.

리눅스에는 apt, 맥에는 brew 가 있습니다. 윈도우에도 같은 일을 하는 도구가 있고, 그것도 셋입니다. 이 글은 winget·Chocolatey·Scoop 이 무엇이 다른지, 어느 것을 골라야 하는지 정리합니다. 결론을 먼저 적으면 winget 으로 시작하고 모자란 부분만 나머지 둘로 채우면 됩니다.

winget 은 이미 컴퓨터에 들어 있습니다

winget 은 마이크로소프트가 만든 공식 도구입니다. 윈도우 11 에는 처음부터 들어 있고, 윈도우 10 도 최신 버전이면 스토어의 '앱 설치 관리자'(App Installer)에 함께 담겨 옵니다. 따로 설치할 것이 없다는 뜻입니다. 터미널을 열고 아래를 쳐서 버전이 나오면 준비된 상태입니다.

winget --version

쓰는 법은 세 가지만 알면 충분합니다. 이름으로 찾고, 아이디로 설치하고, 한꺼번에 업데이트합니다.

winget search git
winget install Git.Git
winget upgrade --all

winget search 결과에는 '장치 ID' 칸이 있습니다. 설치할 때는 이름 대신 이 아이디를 쓰는 편이 안전합니다. 이름이 비슷한 엉뚱한 패키지가 잡히는 일을 막아 줍니다.

Chocolatey 와 Scoop 은 winget 이 비운 자리를 채웁니다

Chocolatey 는 2011년부터 있던 선배입니다. 커뮤니티 저장소에 1만 개 가까운 패키지가 있고, 패키지마다 설치 스크립트를 직접 들고 있어서 설치 옵션을 세밀하게 다룹니다. 기본 설치 위치는 C:\ProgramData\chocolatey 이고 관리자 권한이 필요합니다. 오픈소스 판은 Apache 2.0 라이선스라 회사에서 써도 무료이고, 기능을 더한 유료 기업용 판이 따로 있습니다.

Scoop 은 성격이 반대입니다. 프로그램을 사용자 폴더(C:\Users\<사용자>\scoop) 안에만 풀어 놓기 때문에 관리자 권한이 필요 없고 레지스트리도 건드리지 않습니다. 회사 컴퓨터에서 관리자 권한을 받지 못하는 사람에게는 이 점이 결정적입니다. 패키지는 '버킷'이라는 묶음으로 나뉘고, 기본 버킷에 없으면 scoop bucket add extras 처럼 버킷을 더 붙입니다. 제 컴퓨터에서 확인한 버킷 규모는 main 1,637개, extras 2,372개, java 336개였습니다.

Scoop 은 관리자 권한이 아닌 보통 파워셸 창에서 두 줄로 설치됩니다. 첫 줄은 스크립트 실행을 허용하는 설정입니다.

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

컴퓨터를 새로 세팅할 때 값어치가 나옵니다

프로그램 하나를 깔 때는 명령이나 마우스나 비슷합니다. 차이가 벌어지는 지점은 컴퓨터를 새로 받았을 때입니다. winget 은 지금 깔린 프로그램 목록을 파일로 뽑고, 그 파일로 새 컴퓨터에 한 번에 되살립니다.

winget export -o apps.json
winget import -i apps.json --accept-package-agreements --accept-source-agreements

뽑아낸 apps.json 은 그냥 텍스트 파일이라 메모장으로 열어 필요 없는 줄을 지워도 됩니다. 뒤에 붙인 두 옵션은 설치 중 나오는 동의 창을 자동으로 넘기는 것으로, 옵션 없이 실행하면 프로그램마다 확인을 기다리며 멈춰 섭니다.

정리

윈도우도 명령으로 프로그램을 설치하고 업데이트합니다. winget 은 이미 깔려 있으니 따로 준비할 것이 없고, 관리자 권한이 없으면 Scoop, 설치 옵션을 세밀하게 다뤄야 하면 Chocolatey 를 더합니다. 셋은 서로 부딪히지 않으니 한 컴퓨터에 같이 두고 씁니다.

지금 터미널을 열어 winget upgrade 만 쳐 보시기 바랍니다. 그동안 밀려 있던 업데이트가 몇 개인지 확인하는 데 몇 초면 됩니다.
