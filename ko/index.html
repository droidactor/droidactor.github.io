3. 광고와 동의

이 앱들은 무료이며, 광고를 게재하는 앱은 Google AdMob(Google Mobile Ads SDK)을 통해 광고를 표시합니다. 도토리 YouTube Downloader 는 광고를 게재하지 않습니다. Google 의 데이터 공개 문서에 따르면 이 SDK 는 광고 제공, 측정·분석, 부정행위 방지를 위해 다음 정보를 자동으로 수집하거나 Google 및 광고 서비스 제공자와 공유할 수 있습니다.

  • IP 주소 — 대략적인 지역 추정에 사용될 수 있습니다
  • 앱 실행, 탭, 광고 조회 등 앱·광고 상호작용

  • Android 광고 ID, 앱 세트 ID 등 기기 또는 계정 식별자

광고 SDK 가 전송하는 데이터는 전송 중 암호화됩니다. 광고의 개인화 여부와 실제 처리 범위는 사용자의 동의, 지역, Android 광고 설정, AdMob 설정에 따라 달라집니다. 그 처리에는 Google 자체 정책이 적용되며, 이 절 끝에 링크를 두었습니다.

저희가 지키는 두 가지 원칙이 있습니다. 첫째, Google User Messaging Platform 으로 동의가 확인되기 전에는 광고 SDK 를 초기화하지 않습니다 — 동의 창이 어떤 광고 요청보다도 먼저입니다. 둘째, 2절의 기술적 식별자는 광고 SDK 에 전달하지 않습니다. 스캔한 네트워크나 페어링한 host 에 관한 어떤 정보도 광고주에게 가지 않습니다.

6. 사용자의 권리와 데이터 삭제

저희가 보유한 개인정보가 없으므로, 저희 쪽에 열람·정정·삭제를 요청할 대상이 없습니다. 앱이 저장한 것은 전부 기기에 있습니다 — 앱을 삭제하면 앱이 스스로 저장한 것은 모두 함께 지워지고, Android 설정에서 앱 저장공간을 지우면 삭제 없이 초기화됩니다. Google 이 처리하는 광고 데이터는 기기의 광고 설정과 앱 안의 개인정보 옵션에서 관리하실 수 있습니다.

한 가지 예외가 있습니다. 온드로이드 캘린더에서 기기 캘린더에 저장한 음력 기념일은 앱의 저장공간이 아니라 그 캘린더의 일정입니다. 앱을 지운 뒤에도 캘린더에 남으므로, 더 필요하지 않으면 캘린더 앱에서 직접 지워야 합니다.

7. 앱별 사항

입력한 키와 포인터 이동은 페어링한 host 로 블루투스를 통해서만 전달되며, 다른 곳으로는 가지 않습니다. 키 입력은 기록·저장되지 않고 저희에게 전송되지도 않습니다 — 앱은 현재 눌려 있는 키를 추적할 만큼의 상태만 메모리에 유지합니다. 검증된 host 의 주소는 재연결을 위해 로컬에만 저장하며, 표시할 때는 마스킹합니다. 위치 권한은 요구하지 않습니다.

앱 코드에는 clipboard 를 읽는 API 가 없습니다. 시스템 키보드로 입력란에 붙여 넣은 내용은 직접 입력한 문자열과 똑같이 처리됩니다 — 앱이 HID usage 와 modifier 로 변환하고 host 에는 키보드 report 만 전달되며, 원문 문자열은 남지 않습니다. 블루투스 bond 를 제거하면 해당 host 의 저장 기록도 함께 삭제됩니다.

진단 파일을 export 하면 Android 문서 선택기에서 직접 고른 위치에만 저장되며, 생성 시점에 마스킹됩니다 — host 블루투스 주소는 redacted_at_creation 으로 대체되고, host 표시 이름과 입력 문자열·clipboard 내용은 아예 제외됩니다. 광고 슬롯은 보고 있는 화면이 아니라 세션 상태로 판정합니다 — 유휴·연결됨 상태에서만 허용하고 연결 진행 중·복구·격리 상태에서는 표시하지 않으며, 트랙패드 면과 키보드 면에는 광고를 두지 않습니다.

앱이 열려 있고 Wi-Fi 에 연결되어 있으면, 현재 로컬 IPv4 주소에서 산출한 /24 대역의 host 에 선택한 TCP 포트(기본 22)를 자동으로 시도합니다 — 이 자동 탐색이 발견 기능 그 자체입니다. 자격증명은 사용자가 저장을 선택하지 않으면 영구 저장하지 않으며, 저장한 것은 저장된 접속 목록에서 대상별로 삭제할 수 있습니다. 접속하는 SSH 서버는 저희가 선택하거나 운영하지 않으므로, 그 서버가 세션을 어떻게 처리하는지는 서버 운영자의 정책이 적용됩니다. 본인이 소유하거나 관리 권한을 받은 네트워크에서만 사용하십시오.
