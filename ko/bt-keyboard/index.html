Dotori Bluetooth Keyboard

com.droidactor.bt_keyboard

폰을 블루투스 HID 키보드+마우스로 만들어, 상대 기기에 아무것도 설치하지 않고 PC·TV 를 조작합니다. host 에는 평범한 블루투스 키보드로 보입니다 — 수신기 동글도, 전용 소프트웨어도, 계정도 필요 없습니다.

출시 준비 중 개인정보

하는 일

네 가지이고, 각각을 예상 밖의 동작 없이 하는 것을 목표로 합니다.

진짜 HID 키보드

폰이 스스로를 블루투스 HID 장치로 알립니다. 블루투스 키보드를 받아들이는 기기라면 Windows·macOS·Linux·스마트 TV·셋톱박스 무엇이든 별도 설정 없이 연결됩니다.

트랙패드와 가로 스크롤

포인터 이동·클릭·양방향 스크롤을 키보드와 같은 HID 세션으로 마우스 report 로 보냅니다.

링크를 건너가도 살아남는 한글 입력

한글은 전송 전에 자모 keystroke 로 분해해 host 의 IME 가 조합하게 합니다 — 완성된 음절을 그대로 보내면 동작하지 않는 환경에서 통하는 방식입니다.

믿는 host 로 재연결

검증된 host 의 주소를 기기에 보관해, 폰이 잠기거나 범위를 벗어난 뒤에도 세션이 돌아옵니다. 표시할 때는 어디서든 마스킹합니다.

개인정보

입력한 키와 포인터 이동은 페어링한 host 로 블루투스를 통해서만 전달되며, 다른 곳으로는 가지 않습니다. 키 입력은 기록·저장되지 않고 저희에게 전송되지도 않습니다 — 앱은 현재 눌려 있는 키를 추적할 만큼의 상태만 메모리에 유지합니다. 위치 권한은 요구하지 않으며, 앱 코드에는 clipboard 를 읽는 API 가 없습니다.

진단 파일은 생성 시점에 마스킹됩니다 — host 블루투스 주소는 redacted_at_creation 으로 대체되고, host 표시 이름과 입력 문자열·clipboard 내용은 아예 제외됩니다.
