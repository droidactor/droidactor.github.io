Dotori WIFI Scout

com.droidactor.wifi_scout

접속 중인 Wi-Fi 의 사설망 대역을 훑어 응답하는 장비를 IP │ 종류 │ Note 로 식별합니다. 낯선 현장에 들어가 무엇을 건드리기 전에 네트워크에 실제로 무엇이 있는지 알아야 하는 순간을 위한 도구입니다.

출시 준비 중 개인정보

하는 일

지금 붙어 있는 대역을 훑는다

스캔 범위는 폰이 접속한 Wi-Fi 에서 산출합니다 — CIDR 을 직접 입력하지 않습니다. 응답한 장비마다 IP·종류·Note 한 행이 남습니다.

장비가 스스로 알리는 정보로 식별

mDNS·SSDP·WSD·NetBIOS 응답, 열린 포트와 배너, 그리고 MAC/OUI 접두어로 추정한 제조사를 함께 씁니다.

산업용 장비는 더 조심히

PLC 포트는 후보로만 표시합니다. identity 조회는 사용자가 그 행을 승인한 뒤 한 주소로 보내는 read-only 요청 1회이며, 이런 장비에 쓰기를 하지 않습니다.

SSH 로 넘겨주기

결과 행을 Dotori SSH Scout 에 딥링크로 넘길 수 있습니다. 이 링크는 host 와 port 만 싣고 사용자명·비밀번호는 절대 전달하지 않습니다.

결과가 달라지는 이유

스캔은 존재하는 것이 아니라 응답한 것을 보고합니다. VLAN·방화벽·client isolation·장비 자체 설정이 모두 그림을 바꿉니다 — 조용한 결과는 비어 있는 망이 아니라 잘 분리된 망이라는 뜻일 수 있습니다. 앱은 관측한 사실을 적고 해석은 사용자에게 맡깁니다.

앱 밖으로 나가는 동작은 두 가지이며 사용자가 선택할 때만 일어납니다. CSV 내보내기는 결과 텍스트를 클립보드에 복사하고, 장비 웹 UI 열기는 선택한 로컬 URL 을 기본 브라우저로 넘깁니다.

본인이 소유하거나 관리 권한을 받은 네트워크·장비에서만 사용하십시오. 권한 없는 네트워크를 스캔하는 것은 어떤 도구를 쓰든 문제가 됩니다.

개인정보
