도토리 GPS 기록기

com.droidactor.gps

현재 위치를 저장하고 이동 경로를 기록하며 GPX로 내보냅니다. 기록은 기기에 보관합니다.

기능

  • 메모와 함께 현재 위치 저장
  • 시간·거리 또는 두 조건으로 이동 경로 기록
  • 일시정지·재개, 여정 통계와 경로 미리보기
  • 외부 지도 열기·공유·GPX 내보내기
  • JSON 백업·복원, 한국어·영어와 테마

화면

공공장소 좌표로 만든 시연용 기록입니다.

요구사항과 한계

Android 8.0 이상. 위치 측정에는 위치 권한이 필요합니다. 사용자가 시작한 여정은 일시정지·종료할 때까지 화면이 꺼져도 기록할 수 있습니다. 정확도는 기기와 환경에 따라 달라집니다. 경로 미리보기에는 지도 배경이 없습니다. 긴급 구조·전문 측량용이 아닙니다.

개인정보

위치 기록은 기기에 보관합니다. 첫 화면 지도는 Google 지도 서비스를 이용합니다. 외부 지도·공유·내보내기는 사용자가 선택한 내용을 다른 앱으로 전달합니다. Google Mobile Ads는 별도 광고 데이터를 처리합니다.
