도토리 GPS 기록기

com.droidactor.gps

등산 지도와 받는 사람이 고르는 위치 공유. 걸음 수 기록은 새 버전에서 제공될 예정입니다.

배포 안내(2026-11-05): 현재 스토어 공개본에는 걸음 수 기록이 없습니다. 아래 걸음 수 화면은 배포 전 새 버전의 시연이며, 업데이트 공개 후 사용할 수 있습니다.

주요 기능

지도·장소 탐색

국내 등산로·등고선을 선택해 다운로드하고 지도에 표시합니다. 설치한 지명·지역 상호 자료는 이름 앞부분과 한글 초성으로 검색하며 온라인 주소 검색도 제공합니다.

장소 저장·되돌아가기

장소를 메모·분류와 함께 저장하고 방향·직선거리로 돌아갈 방향을 확인합니다. 주차 위치에는 내 차로가 표시되며 외부 지도 앱 길찾기로 연결할 수 있습니다.

위치는 내가 보내고, 지도 앱은 받는 사람이 선택

위치 링크를 받은 사람이 공유 페이지에서 카카오맵·네이버지도·티맵·Google 지도 중 자신이 사용하는 앱을 고릅니다. Android에서 확인했으며 각 지도 앱의 설치·이용 조건이 적용됩니다.

경로 기록과 걸음 수 업데이트 시연

시간·거리 기준으로 경로를 기록하고 거리·총 소요시간·이동 시간·속도·오른 높이를 확인합니다. 새 버전의 걸음 수 함께 기록을 켜면 여정 중 휴대폰 센서로 측정한 걸음 수도 저장합니다.

속도계·HUD

큰 숫자 GPS 속도계와 좌우 반전 HUD를 사용합니다. 전체 화면 HUD에는 광고가 보이지 않으며 직접 정한 기준속도를 넘으면 진동합니다.

119 위치 전달

현재 좌표·계산한 국가지점번호·정확도·측정 시각을 담은 119 문자 작성 화면을 엽니다. 상황을 추가하고 직접 전송합니다.

기기 내 기록·백업

계정 없이 기록을 기기에 보관합니다. JSON으로 기록과 걸음 수를 백업·복원하며 복원은 기존 기록을 전체 교체합니다.

GPS 상태·좌표 도구

정확도·고도·위성 신호를 확인하고 소수 위경도·도분초·Plus Code를 표시하거나 입력합니다.

경로 불러오기·따라가기

공유받은 경로 파일을 지도에 불러와 기록하며 따라가고 지속 이탈 시 진동을 받습니다. 내 경로도 파일로 저장·공유합니다. GPX에는 걸음 수가 포함되지 않습니다.

화면

경로·메모·걸음 수는 공공장소를 사용한 시연용 예시입니다.

요구사항과 한계

Android 8.0 이상. 위치 권한이 필요하며 걸음 수 기록에는 지원 센서가 필요하며 신체 활동 권한은 필요한 경우 요청합니다. 걸음 수는 여정 중에 측정합니다. 화면 꺼짐 기록은 기기·절전 설정·수신 환경의 영향을 받습니다. 배경지도는 온라인이며 설치한 검색·등산로·등고선 자료만 오프라인으로 읽습니다. 등산로는 주로 2016~2019년 자료로 모든 코스나 현재 개방 상태를 보장하지 않습니다. 돌아가기는 직선 방향이며 HUD 기준속도는 사용자가 정한 값입니다. 119 문자는 직접 전송합니다. GPS·걸음 수·속도는 오차가 있으며 긴급 구조·안전·전문 측량을 보장하지 않습니다.

개인정보

위치·경로·메모·걸음 수 기록은 기기에 보관합니다. 지도는 Google Maps, 광고는 Google Mobile Ads의 데이터 처리 방침을 따릅니다. GPS 기록·메모·걸음 수를 광고 요청에 넣지 않습니다. 외부 지도·공유·내보내기는 사용자가 선택한 내용을 전달합니다.
