도토리 QR·바코드 스캐너

com.droidactor.qr

카메라·사진·공유 이미지의 QR코드와 바코드를 읽고, 링크는 열기 전에 이동할 곳을 먼저 확인하세요. QR코드와 바코드를 직접 만들어 공유할 수도 있습니다.

찍으면 바로 결과

스캔할 때마다 뜨는 전면 광고나 업그레이드 화면이 없습니다. 광고는 화면 위쪽 배너 하나뿐입니다. 링크·연락처·Wi-Fi는 저절로 열리거나 저장되지 않고, 결과 화면에서 할 일을 직접 고릅니다. 모든 기능이 무료이며 구독이나 인앱 결제가 없습니다.

링크는 열기 전에 확인

링크는 이동할 곳을 크게, 전체 주소를 그 아래에 보여 줍니다. 단축 URL 서비스, 암호화하지 않는 주소(http), IP 숫자 주소, 국제화 문자, @ 앞의 사용자 정보, 앱 설치 파일(.apk)이면 안내를 붙입니다. 안내는 주소의 모양만 알려 주며 사이트가 안전한지 판정하지 않습니다.

상자 안의 코드만

가이드 상자 밖의 코드는 읽지 않습니다. 상자 안에 코드가 여러 개면 하나를 고릅니다. 갤러리 사진이나 채팅 앱·스크린샷 등 다른 앱에서 공유한 이미지는 전체에서 찾고, 이미지는 저장하지 않습니다.

QR코드 만들기와 바코드 생성

텍스트·링크·Wi-Fi·연락처·전화번호·문자·이메일 중 담을 내용을 고르고 칸을 채우면 입력하는 대로 QR코드가 그려집니다. 바코드는 읽는 형식과 같은 12가지로 만들고, EAN·UPC는 검사 숫자를 자동으로 붙입니다. 만든 코드는 이미지로 공유하거나 갤러리에 저장합니다(Android 10 이상). 스캔 결과에서 코드로 보이기를 누르면 읽은 코드를 화면에 띄워 보여 줄 수 있습니다. 공유하거나 저장한 코드는 만든 코드 표시와 함께 기록에 남습니다.

동작과 기록

Wi-Fi·연락처·일정은 시스템 확인 화면을 거쳐 추가하고, 전화·문자·메일, 지도 앱으로 위치 열기, 상품 바코드 웹 검색, 복사와 공유를 할 수 있습니다. 스캔 기록은 이 폰에 최대 500개까지 저장하며 검색·삭제할 수 있습니다. 읽고 만드는 코드: QR코드, Aztec, Data Matrix, PDF417, EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, Codabar, ITF. Android 8.0 이상이 필요합니다. 배너 광고가 있습니다. 한국어·영어, 밝은·어두운 테마를 지원합니다.

상품 바코드 정보 조회

상품 바코드 결과에서 조회를 누르면 무료 공개 DB에서 상품명·브랜드·규격을 찾습니다. 조회할 때만 바코드 번호를 보내며 미등록 상품은 웹에서 검색할 수 있습니다. 정보가 없거나 오래됐을 수 있으므로 실제 상품 표시를 확인하세요.

데이터 출처: Open Food Facts, Open Beauty Facts, Open Products Facts 기여자. Open Database License (ODbL 1.0).

개인정보

카메라 화면과 사진·공유받은 이미지는 이 폰 안에서 코드를 읽는 데만 쓰고 저장하거나 보내지 않습니다. 읽은 코드의 기록은 이 폰의 앱 전용 저장소에만 두며 Android 자동 백업·기기 간 이전에서 제외합니다. 기록 저장은 설정에서 끌 수 있고, 기록 화면에서 지우거나 앱을 제거하면 삭제됩니다. 직접 만든 코드는 이 폰에서 만들며, 만들기 자체에는 네트워크를 사용하지 않습니다. 공유나 갤러리에 저장을 누른 코드는 같은 기록에 남습니다. 갤러리에 저장을 고르면 코드 이미지를 사진 앨범(DotoriQR)에 저장합니다. 이 이미지는 사진에 접근할 수 있는 다른 앱도 볼 수 있고, 앱을 제거해도 남으므로 갤러리에서 지웁니다. 상품 바코드 결과에서 상품 정보 조회를 누르면 필요한 순서대로 Open Food Facts·Open Beauty Facts·Open Products Facts에 바코드 번호를 전송합니다. 해당 서비스는 접속 IP·앱 버전·앱 언어도 받습니다. 이미지·다른 QR 내용·스캔 기록은 보내지 않습니다. 조회는 자동으로 실행하지 않습니다. 받은 상품 정보는 앱 메모리에서만 처리하며 파일이나 스캔 기록에 저장하지 않습니다. 최근 조회 결과 최대 32건을 10분 동안 재조회에 재사용합니다. 공급자의 처리는 해당 서비스의 개인정보 처리방침을 따릅니다. 개발자 계정·개발자 서버·클라우드 동기화는 없습니다. 카메라 권한만 요청하며 위치·연락처·캘린더·저장소 전체·마이크 권한을 요청하지 않습니다. 연락처·일정·Wi-Fi 저장, 전화·문자·메일, 지도·웹 검색·공유는 사용자가 고른 시스템 앱이나 다른 앱으로 넘기며 그 이후의 처리는 해당 앱의 방침을 따릅니다. Google AdMob/UMP와 Play 업데이트는 네트워크를 사용할 수 있습니다. 개인정보 선택에 따라 광고 SDK가 IP 기반 대략적 위치·광고 상호작용·진단·기기 ID를 처리할 수 있습니다. 설정에서 광고 개인정보 옵션을 다시 열 수 있습니다. 개인정보 문의는 droidactor@gmail.com으로 받습니다.
