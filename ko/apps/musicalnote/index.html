도토리 채보

com.droidactor.musicalnote

무반주 멜로디 파일이나 직접 녹음한 소리를 폰 안에서 악보 초안으로 만들고, 원음과 비교해 수정·보관·MIDI/MusicXML/PDF로 내보내는 앱입니다.

앱 화면

기기 안에서 만드는 단선율 악보 초안

귀로 한 음씩 받아 적는 수고를 줄이고, 자동 채보에서 어긋난 부분을 원음과 대조하며 빠르게 고치는 흐름에 맞췄습니다. Google Play에서 설치할 수 있습니다.

  • 오디오 파일 가져오기: MP3·M4A·WAV 등 기기 디코더가 지원하는 파일을 Android 문서 선택기나 공유 메뉴로 불러옵니다. 파일(최대 100MB)은 앱 내부 저장소에 복사해 원본 파일 접근 권한이 사라져도 저장한 곡을 다시 들을 수 있게 합니다.
  • 앱 내 녹음: 사용자가 녹음을 명시적으로 누르고 권한을 허용했을 때만 마이크를 열며, 녹음한 소리는 앱 내부 WAV 파일로 저장합니다.
  • 구간 선택과 수동 박자·빠르기: 최대 120초 구간을 고르고 빠르기(40–240 BPM)와 박자(2/4–6/4)를 사용자가 직접 지정한 뒤, 기기 안 단선율 DSP 분석으로 16분음표 격자 악보 초안을 만듭니다.
  • 악보 편집: 음표 선택, 음 높이·길이 변경, 삽입·삭제·실행 취소, 전체 반음 조옮김, 제목·BPM·박자 수정을 제공합니다.
  • 원음·악보 비교 재생: 악보음과 원음을 비교해 듣고, 느리게 재생, 선택 마디 반복, 악보와 연동된 클릭·카운트인으로 연습합니다.
  • 로컬 보관과 내보내기: 프로젝트와 원음을 앱 전용 저장소에 보관하고, MIDI·MusicXML·PDF 는 Android 문서 만들기로 사용자가 고른 위치에 저장합니다.

도토리 튜너·메트로놈과의 역할 구분

도토리 튜너·메트로놈은 실시간 단음 조율과 독립 연습 메트로놈에 집중합니다. 도토리 채보는 음원·녹음의 악보 초안 생성, 음표 수정, 원음 비교 재생과 파일 내보내기에 집중합니다.

모든 기능 무료

계정·구독·인앱 결제 없이 모든 기능을 무료로 제공입니다. 화면 위쪽에 배너 광고(전체 이용가 G 등급 요청)가 표시되며, 지역에 따라 광고 개인정보 선택을 제공합니다.

사용 전 확인과 알려진 한계

  • 무반주 단선율(한 번에 한 음씩 진행하는 멜로디) 전용입니다. 여러 악기가 섞인 혼합곡, 화음·다성부, 악기별 전체 총보, 자동 코드 추출, 가사 인식은 지원하지 않습니다.
  • 자동 채보는 완벽한 최종 악보를 보장하지 않습니다. 주변 소음, 배음, 비브라토나 일정하지 않은 박자에 따라 음 누락·옥타브 오차·리듬 오차가 생길 수 있으므로 원음과 비교해 수정하는 초안 도구로 사용해 주세요.
  • 빠르기(40–240 BPM)와 박자(2/4–6/4)는 자동 추정으로 오인시키지 않도록 사용자가 직접 정합니다.
  • 녹음과 재생은 앱 화면을 벗어나면 끝납니다.
  • Android 8.0 이상이 필요합니다. 마이크가 없는 기기에서도 오디오 파일 채보와 악보 편집을 쓸 수 있습니다.

개인정보

불러온 오디오 파일(최대 100MB), 녹음 WAV 파일, 저장한 악보 프로젝트와 설정값은 이 폰의 앱 전용 저장소에만 두며 Android 자동 백업·기기 간 이전에서 제외합니다. 마이크 권한은 사용자가 녹음을 누르고 허용했을 때만 요청하며, 화면을 벗어나면 녹음과 재생을 끝냅니다. 원음과 악보는 개발자 서버나 광고 SDK 에 보내지 않습니다. 내보낸 MIDI·MusicXML·PDF 는 Android 문서 선택 화면에서 고른 위치에 저장되며 그 위치에서 직접 삭제해야 합니다. Google AdMob/UMP, Play 업데이트, droidactor.github.io 의 서명된 정적 운영 공지 확인에는 네트워크를 사용할 수 있으며, 개인정보 선택에 따라 광고 SDK 가 IP 기반 대략적 위치·광고 상호작용·진단·기기 ID 를 처리할 수 있습니다.
