# Dotori GPS offline data

Selected downloads only; no database is bundled in the app.

Sources: [GeoNames](https://www.geonames.org/) (CC BY 4.0), collected 2026-11-03; [SEMAS store data](https://www.data.go.kr/data/15083033/fileData.do), as of 2026-09-30, unrestricted reuse.

Hiking: [Korea Forest Service](https://www.data.go.kr/data/3034022/fileData.do), mostly 2016 and some 2019 surveys; [Korea National Park Service](https://www.data.go.kr/data/15091972/fileData.do), as of 2018-12-31. Both allow unrestricted reuse. Source archives collected 2026-11-04. Known closed/controlled KFS features are excluded. Coverage is incomplete; these are informational trail lines, not live closure information or offline background maps.

The signed manifest identifies immutable versioned chunks. Generation and update contract: mobile repository apps/gps/docs/data-updates.md.
