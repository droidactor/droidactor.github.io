Dotori Korea Hiking — Foreground service review

Package com.droidactor.mountain, version 1.0.0 (1). These recordings use the release installation built from the submitted App Bundle.

Health: hike session steps

An Android 11 test phone shows the user starting a hike, granting location and physical activity permissions, viewing separate daily and hike step totals, and pausing and resuming the session. The phone remained stationary, so the step totals stay at zero. The map is hidden for device location privacy. This is a permission and service demonstration, not a walking accuracy test.

Location: course following and hike recording

An Android 16 emulator shows a bundled course preview, the user starting course following, location permission, recording, and the ongoing notification with pause and resume controls. Public mountain coordinates are simulated; the emulator has no step sensor. Partial map views are hidden. The clip does not establish outdoor accuracy or long background endurance.
