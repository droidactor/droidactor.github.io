Dotori Korea Bike — Foreground service review

Package com.droidactor.bike, version 1.0.0 (1). The recording uses a pre-release test build of the same app code with ads turned off for clarity.

Location: bike path following and ride recording

An Android 16 emulator shows the user choosing the Hangang River Bike Path (south bank), starting path following and a ride, granting location (while using the app) and notification permissions, and viewing live speed and distance on the cycle computer. The ongoing notification shows the recording distance with Pause and Finish controls. After the user presses Home, the ride keeps recording through the location foreground service and the notification distance keeps increasing; tapping the notification returns to the app, and the user finishes the ride, which is then saved in Records. Public bike path coordinates are simulated on the emulator. The clip does not establish outdoor GPS accuracy or long background endurance.

Open the location demonstration video

Ride recording starts only through user action and can be paused or finished by the user from the app or the notification. The app does not request background location permission.
