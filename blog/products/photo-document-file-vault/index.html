Hide photos and PDFs in one file vault

17 November 2026

https://play.google.com/store/apps/details?id=com.droidactor.vault

In short. Showing someone a photo can feel awkward when personal pictures or an ID scan sit beside it. Dotori File Vault is a file vault for photos, videos, PDFs and other personal files. I made this Android app. Adding files, exporting them and making backups are free, with no subscription.

Dotori File VaultEncrypt any file and keep it to yourself

Deleting the app also deletes the files inside its vault.

Before you uninstall it, export the files you need and open the saved copies to check them. Reinstalling the app and entering the same password will not bring a deleted vault back.

Keep photos and documents together and organize them into folders. View supported photos, videos, PDFs and text inside the app. Imported files are checked before the app offers to delete their originals. Use a password or a supported fingerprint to open the vault. An encrypted backup lets you move its contents to another phone.

Keep documents beside your photos

If you only hide photos from the gallery, a contract or ID scan can remain visible in Downloads. Dotori File Vault accepts documents and ZIP files as well as photos and videos. You choose each file through the system picker or another app's Share menu.

Create a private folder for documents and another for personal pictures. Keeping them in one list makes it easier to check what you have stored. The app does not scan your phone and automatically collect every file.

Check imported copies before deleting originals

File encryption is followed by a check. The app decrypts the imported copy and compares its size and SHA-256 hash with the original. Only verified imports are offered for original deletion. Automatic original deletion is off by default.

To hide videos or pictures, remember that adding them to the vault leaves the originals in place. Read the import result and choose whether to keep or delete them. Android may ask for permission, and the source provider can prevent deletion.

  1. Add the files you want to store.
  2. Check the import result after verification finishes.
  3. Choose to delete the originals and approve any Android confirmation.
  4. Read the deletion result and open the stored files inside the vault.

If you want to inspect the copy yourself first, choose to keep the originals. Open the files in the vault, then remove the originals with your gallery or file manager. The Delete action in the vault removes the vault's copy, so it serves a different purpose.

Files received through Share remain in the source app. Cloud backups and gallery trash can also retain separate copies. Deleting an original here does not erase those copies. Ordinary file deletion is not secure erasure.

Read supported files without exporting them first

You can read supported encrypted documents, including PDFs, inside the app. Supported photos, videos and text can also be viewed without saving a separate unencrypted file. This avoids exporting a contract just to check one detail.

Storage support and viewing support are different. Other formats, such as ZIP archives and some documents, need another app to open them. That app receives a decrypted file and may keep its own copy.

Choose a password, a fingerprint or both

Set a password when creating your vault and keep the recovery key somewhere outside the phone. You can use fingerprint unlock on supported devices. Settings lets you choose a password, fingerprint authentication or both.

Turning the screen off locks the vault. Leaving the app also locks it. A grace period of up to five minutes applies to file selection and deletion confirmation. Opening a file in another app has the same grace period. These exceptions let you finish an operation without the vault immediately closing.

The normal app blocks screenshots and recent-app previews. It does not promise complete protection on a rooted or compromised phone. Exported files and copies kept by other apps must be managed in their own locations.

Export and backup are free, with a banner ad

All features are free, including the ability to export files and create an encrypted backup. There is no subscription or export fee. The app displays a banner ad at the top.

Export and backup serve different purposes:

MethodWhat it savesWhen to use it
ExportAn unencrypted ordinary fileBefore deleting the app, or to use the file elsewhere
Encrypted backupA backup for restoring the vaultMoving phones or restoring after a reinstall

Choose where exported files are saved, then open them there and check their contents. They are ordinary files outside the vault and can be visible to other apps.

Create a backup in Settings and keep the backup file outside this phone. Use a PC or a cloud storage location you choose. Restoration needs the password or recovery key that applied when that backup was made.

There is no developer account or automatic cloud sync. Vault contents and file names are not sent to the developer or advertising SDK. A cloud document provider may upload an export or backup if you choose it as the destination. Advertising uses the network and the advertising SDK.

Export before uninstalling the app

Uninstalling the app or clearing its data deletes this phone's vault and every file inside it.

If you also deleted the originals, recovery needs an outside copy or a previously saved backup.

Before uninstalling the app:

  1. Export every file you need to a location outside the app.
  2. Open the saved files and check that their contents are correct.
  3. If you also want to keep the vault as a vault, create a current encrypted backup and store it outside the phone.
  4. Check the saved files and their locations before uninstalling.

The vault is excluded from Android automatic backup and device transfer. Reinstalling cannot recreate files, even with the same password, fingerprint or recovery key. Those credentials unlock an existing vault or backup; they do not contain your files.

If you have a backup, choose Restore from backup on the app's first screen. It restores only the files included when the backup was created. Make a new backup before deleting the app if you have added files since then.

Try Dotori File Vault with an unimportant file first: add it, open it and export it. Before deleting the app, export the files you need and check that the saved copies open.
